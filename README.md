# airway-rnaseq-exploration-r
This project explores the Bioconductor Airway RNA-seq dataset using R.

Objectives:
- Understand the structure of a SummarizedExperiment object
- Explore sample and gene metadata
- Extract RNA-seq count data
- Apply log2 transformation
- Visualize gene expression distributions
- Investigate expression changes in FKBP5 between untreated and dexamethasone-treated samples

Tools:
- R
- Bioconductor
- airway package

Key Findings:
- Samples showed similar overall expression distributions.
- FKBP5 expression was consistently higher in dexamethasone-treated samples than untreated samples.
- This reproduces a known glucocorticoid-response pattern in airway cells.
